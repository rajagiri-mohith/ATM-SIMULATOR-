# ATM-SIMULATOR-
A beginner-friendly ATM simulation in C featuring PIN verification, deposits, withdrawals, balance enquiry, mini statements, PIN change, and file handling.
ATM Management System in C

A beginner-friendly ATM Management System developed using the C programming language as a first-year BTech CSE mini project.

This project simulates basic ATM operations, allowing users to select a customer account, verify their PIN, and perform different banking operations.

Features

- Customer account selection (simulated ATM card insertion)
- PIN verification with a maximum of 3 attempts
- Balance enquiry
- Cash withdrawal
- Cash deposit
- Mini statement showing recent transactions
- PIN change
- File handling to save and retrieve account information

Concepts Used

- Structures
- Arrays and strings
- Functions
- Loops and conditional statements
- Switch-case
- File handling ("fopen", "fread", "fwrite", "fclose")

Technologies

- Language: C
- Compiler: GCC / Any C compiler

About

This project was created to understand the practical implementation of C programming concepts through a simple ATM simulation. It is an educational project and does not connect to any real banking system.
